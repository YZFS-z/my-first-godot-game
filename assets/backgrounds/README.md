# 主菜单背景图片目录

将背景图片放入此目录，文件名需与预设ID对应：

| 文件名 | 对应预设 |
|--------|----------|
| classic.png / .jpg | 深色经典 |
| desert.png / .jpg | 沙漠黄昏 |
| forest.png / .jpg | 欧洲森林 |
| snow.png / .jpg | 寒带雪原 |
| night.png / .jpg | 夜幕战场 |
| ruins.png / .jpg | 废墟都市 |

## 使用说明

1. 图片建议分辨率：1920x1080 或更高
2. 支持 .png 和 .jpg 格式
3. 放入对应文件名的图片后，游戏会自动优先加载图片而非渐变背景
4. 未放置图片的预设将使用代码生成的渐变作为兜底
5. 在游戏内：设置 → 游戏性 → 菜单背景 中切换

## 示例

```
assets/backgrounds/
├── desert.jpg
├── forest.png
└── README.md
```

上述目录中，沙漠黄昏和欧洲森林将使用真实图片，其余预设使用渐变。
