# 地图障碍物3D模型目录

放置地图编辑器使用的外部3D模型。

## 支持格式
- .glb / .gltf (推荐)
- .tscn (Godot场景)
- .obj / .fbx / .dae (需Godot导入)

## 使用方法
1. 在地图编辑器中点击"导入模型"，选择外部模型文件
2. 文件会自动复制到此目录
3. 从"选择已导入模型"下拉列表中选择模型
4. 调整缩放滑块，点击地面放置
5. 保存地图后，模型路径会存入地图JSON

## 注意
- 新导入的模型需要Godot重新导入后才能加载（重启游戏或在编辑器中刷新）
- 模型碰撞体基于AABB包围盒自动生成
- 建议模型面数不要太高，避免影响性能
